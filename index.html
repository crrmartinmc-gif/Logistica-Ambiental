SALIDA DE SERVICIO · LOGÍSTICA AMBIENTAL V13 — CONTROL DEL VEHÍCULO OPCIONAL ============================================================ BASE: Esta versión agrega al flujo actual de SALIDA DE SERVICIO un módulo opcional de control/reporte del estado del vehículo. NO reemplaza: - Login - Vehículo asignado - Foto real del vehículo - 4 fotos obligatorias de salida - Kilometraje actual - Observación general - INICIAR VIAJE - Carga de fotos a Google Drive - Registro del servicio La salida NO queda bloqueada por estos controles. ------------------------------------------------------------ 1. UBICACIÓN EN LA APP ------------------------------------------------------------ Debajo de: 2. KILOMETRAJE ACTUAL agregar: 3. CONTROL DEL VEHÍCULO (opcional) Texto: "Reportá una falla o novedad si detectás algo en la unidad." Diseño: Botonera moderna de tarjetas grandes, responsive y táctil. Botones: 🔴 FRENOS "Delanteros / Traseros" 💡 LUCES "Todas las opciones" 🛞 RUEDAS "Según cantidad de ruedas" ⚙️ FALLA MECÁNICA "Motor, caja, dirección, etc." 🏗️ FALLA ESTRUCTURAL "Carrocería, chasis, hidráulica, etc." 🎨 PLOTEO / PINTURA "Estado general del ploteo y pintura" 📄 VERIFICACIÓN TÉCNICA (VTV) "Vigente / Vencida" ------------------------------------------------------------ 2. FRENOS ------------------------------------------------------------ Al tocar FRENOS abrir un panel/modal: REPORTAR FALLA · FRENOS Zona: [ DELANTEROS ] [ TRASEROS ] Estado: [ 🟢 BIEN ] [ 🟠 ATENCIÓN ] [ 🔴 CRÍTICO ] Observación opcional: [ textarea ] Foto opcional: [ 📷 AGREGAR FOTO ] [ CANCELAR ] [ REGISTRAR ] No es obligatorio completar nada para iniciar el viaje. ------------------------------------------------------------ 3. LUCES ------------------------------------------------------------ Al tocar LUCES mostrar: REPORTAR FALLA · LUCES [ ALTAS ] [ BAJAS ] [ GIRO DELANTERO IZQUIERDO ] [ GIRO DELANTERO DERECHO ] [ GIRO TRASERO IZQUIERDO ] [ GIRO TRASERO DERECHO ] [ POSICIÓN ] [ STOP ] [ BALIZAS ] Cada elemento puede seleccionarse y recibir: 🟢 BIEN 🟠 ATENCIÓN 🔴 CRÍTICO Observación opcional. Foto opcional. IMPORTANTE: Usar exactamente estos nombres para evitar duplicados. ------------------------------------------------------------ 4. RUEDAS ------------------------------------------------------------ La botonera se genera dinámicamente según: VEHICULOS.CANTIDAD_RUEDAS Reglas: 4 ruedas: - Delantera izquierda - Delantera derecha - Trasera izquierda - Trasera derecha 6 ruedas: - Delantera izquierda - Delantera derecha - Trasera izquierda exterior - Trasera izquierda interior - Trasera derecha interior - Trasera derecha exterior 10 ruedas: usar las 10 posiciones reales de la unidad, siguiendo la nomenclatura existente de POSICIONES_RUEDAS. Cada posición: 🟢 BIEN / 🟠 ATENCIÓN / 🔴 CRÍTICO No crear posiciones adicionales con nombres alternativos. ------------------------------------------------------------ 5. FALLA MECÁNICA ------------------------------------------------------------ Al tocar: ⚙️ FALLA MECÁNICA mostrar: Sistema / elemento: [ campo de texto ] Estado: [ 🟢 BIEN ] [ 🟠 ATENCIÓN ] [ 🔴 CRÍTICO ] Descripción: [ textarea ] Foto opcional: [ 📷 AGREGAR FOTO ] [ CANCELAR ] [ REGISTRAR FALLA ] Ejemplos: - Motor - Caja - Embrague - Dirección - Suspensión - Frenos hidráulicos - Pérdida de aceite - Pérdida de combustible - Pérdida de aire - Otro La descripción debe quedar en un único registro de falla. ------------------------------------------------------------ 6. FALLA ESTRUCTURAL ------------------------------------------------------------ Al tocar: 🏗️ FALLA ESTRUCTURAL mostrar: Elemento / sector: [ campo de texto ] Estado: [ 🟢 BIEN ] [ 🟠 ATENCIÓN ] [ 🔴 CRÍTICO ] Descripción: [ textarea ] Foto opcional: [ 📷 AGREGAR FOTO ] [ CANCELAR ] [ REGISTRAR FALLA ] Ejemplos: - Carrocería - Chasis - Caja compactadora - Hidráulica - Portón - Paragolpes - Soporte - Otro ------------------------------------------------------------ 7. PLOTEO / PINTURA ------------------------------------------------------------ Nueva botonera: 🎨 PLOTEO / PINTURA "Estado general del ploteo y pintura" Al abrir: PLOTEO / PINTURA Estado: [ 🟢 BIEN ] [ 🟠 ATENCIÓN ] [ 🔴 CRÍTICO ] Observación opcional: [ textarea ] Foto opcional: [ 📷 AGREGAR FOTO ] [ CANCELAR ] [ REGISTRAR ] No utilizar VIGENTE/VENCIDA aquí. Los estados son exclusivamente: BIEN / ATENCIÓN / CRÍTICO. ------------------------------------------------------------ 8. VERIFICACIÓN TÉCNICA (VTV) ------------------------------------------------------------ Nueva botonera: 📄 VERIFICACIÓN TÉCNICA (VTV) "Vigente / Vencida" Al abrir: VERIFICACIÓN TÉCNICA (VTV) Estado: [ ✅ VIGENTE ] [ ⚠️ VENCIDA ] Observación opcional: [ textarea ] Foto opcional: [ 📷 AGREGAR FOTO ] [ CANCELAR ] [ REGISTRAR ] IMPORTANTE: VTV NO utiliza BIEN / ATENCIÓN / CRÍTICO. Sus únicos estados son: VIGENTE VENCIDA ------------------------------------------------------------ 9. REGLA GENERAL DE LOS ESTADOS ------------------------------------------------------------ Para evitar duplicados y confusiones: FRENOS: BIEN / ATENCIÓN / CRÍTICO LUCES: BIEN / ATENCIÓN / CRÍTICO RUEDAS: BIEN / ATENCIÓN / CRÍTICO FALLA MECÁNICA: BIEN / ATENCIÓN / CRÍTICO FALLA ESTRUCTURAL: BIEN / ATENCIÓN / CRÍTICO PLOTEO / PINTURA: BIEN / ATENCIÓN / CRÍTICO VTV: VIGENTE / VENCIDA ------------------------------------------------------------ 10. INICIAR VIAJE ------------------------------------------------------------ El botón: ▶ INICIAR VIAJE NO debe depender del control opcional. Requisitos obligatorios actuales: - 4 fotos de salida - Kilometraje actual Los controles de esta sección son informativos/reportables. El chofer puede: A) No reportar nada → iniciar viaje. B) Reportar una falla → registrar → iniciar viaje. C) Reportar varias fallas → registrar → iniciar viaje. ------------------------------------------------------------ 11. REGISTRO DE DATOS ------------------------------------------------------------ Cada reporte debe quedar asociado a: ID_REPORTE FECHA_HORA ID_SERVICIO ID_CHOFER CHOFER ID_UNIDAD DOMINIO KILOMETRAJE CATEGORIA ELEMENTO POSICION ESTADO OBSERVACION FOTO_URL ORIGEN Categorías normalizadas: FRENOS LUCES NEUMÁTICOS FALLA MECÁNICA FALLA ESTRUCTURAL PLOTEO / PINTURA VTV No crear otra categoría para el mismo elemento. ------------------------------------------------------------ 12. TRAZABILIDAD ------------------------------------------------------------ El reporte queda vinculado a: SERVICIO ↓ CHOFER ↓ VEHÍCULO ↓ KILOMETRAJE ↓ REPORTE ↓ MANTENIMIENTO Esto permitirá posteriormente que el Panel de Control muestre: "AB773LE informó: Falla en freno trasero ATENCIÓN 08/09/2026 08:32 75.000 km Chofer: [nombre] Servicio: [ID_SERVICIO]" ------------------------------------------------------------ 13. DISEÑO VISUAL ------------------------------------------------------------ Las botoneras deben ser grandes, modernas y fáciles de tocar desde un teléfono. Propuesta visual: ┌──────────────────────┬──────────────────────┐ │ 🔴 FRENOS │ 💡 LUCES │ │ Delanteros / Traseros│ Todas las opciones │ ├──────────────────────┼──────────────────────┤ │ 🛞 RUEDAS │ ⚙️ FALLA MECÁNICA │ │ Según la unidad │ Motor, caja, etc. │ ├──────────────────────┼──────────────────────┤ │ 🏗️ FALLA ESTRUCTURAL │ 🎨 PLOTEO / PINTURA │ │ Carrocería, chasis │ Estado general │ ├──────────────────────┴──────────────────────┤ │ 📄 VERIFICACIÓN TÉCNICA (VTV) │ │ Vigente / Vencida │ └─────────────────────────────────────────────┘ Cada tarjeta abre solamente su propio formulario. ------------------------------------------------------------ 14. NOTA DE IMPLEMENTACIÓN ------------------------------------------------------------ Esta V13 debe integrarse sobre la versión actual que ya contiene las 4 fotos obligatorias de salida y el kilometraje. NO eliminar ni modificar el funcionamiento de las 4 fotos obligatorias. NO volver a mostrar la antigua inspección de 26 ítems como formulario obligatorio.
